# Microwave-PTP-link-planning-linkplanner


##  Overview
This project focuses on the design and analysis of a **Point-to-Point (PTP) microwave link** using Cambium Networks LINKPlanner.

The objective is to simulate, evaluate, and optimize a wireless backhaul link between two sites while ensuring high availability, reliability, and performance.

---

##  Objectives
- Design a reliable microwave PTP link
- Analyze path profile and terrain effects
- Ensure Fresnel zone clearance
- Evaluate link budget and performance metrics
- Achieve required availability and throughput

---

##  Tools & Technologies
- **LINKPlanner (Cambium Networks)**  
- RF Link Budget Calculations  
- Path Profile Analysis  
- Google Earth Integration  

 LINKPlanner is a professional RF planning tool used to design PTP and PMP networks with predictable performance before deployment :contentReference[oaicite:0]{index=0}

## Project Description

### 1. Site Configuration
- Defined transmitter and receiver locations
- Imported coordinates and terrain data
- Adjusted antenna heights and parameters

### 2. Path Profile Analysis
- Evaluated Line-of-Sight (LoS)
- Checked Fresnel zone clearance
- Identified obstacles and terrain impact

### 3. Link Budget Calculation
- Transmit Power
- Path Loss
- Receiver Sensitivity
- Fade Margin

### 4. Performance Evaluation
- Availability (%)
- Throughput (Capacity)
- Signal Strength (RSSI)

---

##  Key Results
-  Stable Line-of-Sight link achieved  
-  Acceptable Fade Margin  
-  High availability (carrier-grade target)
